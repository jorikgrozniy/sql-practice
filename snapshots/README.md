# snapshots - представления и материализованные представления

Виртуальные таблицы для фильтрации и переиспользования запросов, генерация дат, операции над множествами и материализованное представление с обновлением.

## Файлы

| Файл | Задание |
|---|---|
| `ex00.sql` | Представления `v_persons_female` и `v_persons_male` |
| `ex01.sql` | Объединение двух представлений в общий список |
| `ex02.sql` | Представление `v_generated_dates` с датами января 2022 |
| `ex03.sql` | Пропущенные дни посещений через представление |
| `ex04.sql` | Симметрическая разность в `v_symmetric_union` |
| `ex05.sql` | Представление `v_price_with_discount` со скидкой 10% |
| `ex06.sql` | Материализованное представление `mv_dmitriy_visits_and_eats` |
| `ex07.sql` | Новый визит и `REFRESH MATERIALIZED VIEW` |
| `ex08.sql` | Удаление всех представлений |

Файлы выполняются по порядку: `ex01` использует представления из `ex00`, а `ex07` обновляет materialized view из `ex06`.

## Запуск

```bash
psql -d sql_practice -f snapshots/model.sql
psql -d sql_practice -f snapshots/ex00.sql
```

Проект продолжает состояние после `DML/ex07.sql`-`DML/ex13.sql`, поэтому для чистой проверки сначала примените `DML/model.sql` и выполните упражнения DML по порядку.
