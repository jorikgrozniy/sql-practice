# DML - изменение данных

Запросы на выборку и изменение данных: `INSERT`, `UPDATE`, `DELETE`, подзапросы и работа с идентификаторами.

## Файлы

| Файл | Задание |
|---|---|
| `ex00.sql` | Пиццы и даты посещений Kate с ценами 800-1000 |
| `ex01.sql` | Меню, которое никто не заказывал |
| `ex02.sql` | Пиццы и пиццерии без заказов |
| `ex03.sql` | Пиццерии, где женщин и мужчин посещало разное число |
| `ex04.sql` | Пиццерии только для женщин и только для мужчин |
| `ex05.sql` | Пиццерии, где был Андрей, но не заказывал |
| `ex06.sql` | Одинаковые пиццы по одинаковой цене в разных пиццериях |
| `ex07.sql` | `INSERT` пиццы Greek pizza |
| `ex08.sql` | `INSERT` с `MAX(id) + 1` и подзапросом |
| `ex09.sql` | Новые посещения Дениса и Ирины |
| `ex10.sql` | Новые заказы Дениса и Ирины |
| `ex11.sql` | `UPDATE` цены Greek pizza на -10% |
| `ex12.sql` | `INSERT ... SELECT` заказов через `generate_series` |
| `ex13.sql` | `DELETE` новых заказов и Greek pizza |

`ex07`-`ex13` изменяют данные и выполняются по порядку.

## Запуск

```bash
psql -d sql_practice -f DML/model.sql
psql -d sql_practice -f DML/ex00.sql
```
