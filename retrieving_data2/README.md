# retrieving_data2 - JOIN и пропуски в данных

Соединения таблиц, генерация отсутствующих дат и обработка `NULL`.

## Файлы

| Файл | Задание |
|---|---|
| `ex00.sql` | Пиццерии без посещений через `LEFT JOIN` |
| `ex01.sql` | Пропущенные даты посещений через `generate_series` |
| `ex02.sql` | `FULL JOIN` и замена `NULL` на `-` |
| `ex03.sql` | Генератор дат, вынесенный в CTE |
| `ex04.sql` | Пиццы с грибами и пепперони с ценами |
| `ex05.sql` | Женщины старше 25 лет |
| `ex06.sql` | Пиццы, которые заказывали Денис или Анна |
| `ex07.sql` | Пиццерия Дмитрия 8 января с ценой ниже 800 |
| `ex08.sql` | Мужчины из Москвы и Самары с пепперони или грибами |
| `ex09.sql` | Женщины, заказавшие и сырную, и пепперони |
| `ex10.sql` | Люди с одинаковым адресом через self-join |

## Запуск

```bash
psql -d sql_practice -f retrieving_data2/model.sql
psql -d sql_practice -f retrieving_data2/ex00.sql
```
