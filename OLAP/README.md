# OLAP - аналитические запросы

Агрегация данных, группировка, CTE и расчёт бизнес-метрик.

## Файлы

| Файл | Задание |
|---|---|
| `ex00.sql` | Количество посещений по людям |
| `ex01.sql` | Топ-4 людей по числу визитов |
| `ex02.sql` | Топ-3 пиццерий по заказам и посещениям |
| `ex03.sql` | Суммарное число заказов и посещений по пиццериям |
| `ex04.sql` | Люди с более чем 3 посещениями через `HAVING` |
| `ex05.sql` | Уникальные имена людей с заказами |
| `ex06.sql` | Заказы, средняя, максимальная и минимальная цена по пиццериям |
| `ex07.sql` | Средний рейтинг всех пиццерий |
| `ex08.sql` | Заказы по адресам и пиццериям |
| `ex09.sql` | Возрастная формула и сравнение со средним возрастом |

## Запуск

```bash
psql -d sql_practice -f OLAP/model.sql
psql -d sql_practice -f OLAP/ex00.sql
```
