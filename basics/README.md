# basics - базовые запросы

Практика базового SQL на схеме пиццерии: фильтрация, сортировка, вычисляемые столбцы и подзапросы.

## Файлы

| Файл | Задание |
|---|---|
| `ex00.sql` | Имена и возраст жителей Казани |
| `ex01.sql` | Женщины из Казани, сортировка по имени |
| `ex02.sql` | Пиццерии с рейтингом 3.5-5 двумя способами: сравнения и `BETWEEN` |
| `ex03.sql` | Уникальные `person_id` по диапазону дат или пиццерии |
| `ex04.sql` | Вычисляемое поле `person_information` |
| `ex05.sql` | Подзапрос в `SELECT`: имена по заказам меню 13, 14, 18 |
| `ex06.sql` | Проверка имени через подзапрос |
| `ex07.sql` | `CASE`-интервалы возрастов |
| `ex08.sql` | Чётные `id` в `person_order` |
| `ex09.sql` | Подзапросы в `SELECT` и `FROM` для посещений |

## Запуск

```bash
psql -d sql_practice -f basics/model.sql
psql -d sql_practice -f basics/ex00.sql
```
