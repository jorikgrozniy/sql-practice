# warehouse_fundamentals - DWH и конвертация валют

Аналитические запросы к несогласованным источникам данных: пользователи, балансы и исторические курсы валют.

## Файлы

| Файл | Задание |
|---|---|
| `ex00.sql` | Суммы балансов по пользователям и типам с последним курсом валюты |
| `ex01.sql` | Детализация операций с ближайшим курсом в прошлом или будущем |

В проекте своя схема: `"user"`, `currency`, `balance`. Таблица `"user"` требует кавычек, потому что `user` - зарезервированное слово.

## Запуск

```bash
psql -d sql_practice -f warehouse_fundamentals/model.sql
psql -d sql_practice -f warehouse_fundamentals/ex00.sql
```
